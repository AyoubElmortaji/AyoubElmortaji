# Ayoub ELMORTAJI Cyberpunk Portfolio

A premium cyberpunk‑neon portfolio built with **HTML, CSS, and JavaScript**.

## Run locally

Use any static server. Examples:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` – app shell
- `styles.css` – cyberpunk neon styling
- `app.js` – routing, rendering, interactivity
- `content/profile.json` – all content and labels

## GitHub Pages

1. Commit the repository to GitHub.
2. In **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/** (root)

The site will be available at:
`https://<github-username>.github.io/<repo-name>/`
